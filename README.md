# GB Day-Ahead Electricity Price Forecasting

Probabilistic (P10 / P50 / P90) half-hourly forecasts of the GB Market Index
Price for the next delivery day, built only from information available at a
09:00 decision cutoff on the day before, and valued in £ through a battery
arbitrage simulation.

> Work in progress. See [PROGRESS.md](PROGRESS.md) for status and
> [DECISIONS.md](DECISIONS.md) for the reasoning behind each choice.
